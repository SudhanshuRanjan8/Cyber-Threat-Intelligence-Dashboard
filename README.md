# Cyber Threat Intelligence Dashboard

The Cyber Threat Intelligence Dashboard is a web-based cybersecurity management system developed as a BCA mini project. The application provides a centralized platform for monitoring and managing cyber threats, Indicators of Compromise (IOCs), vulnerabilities, and security alerts.

The system includes secure user authentication, interactive dashboard analytics, threat simulation, automatic alert generation, and data visualization using Chart.js. It is designed to demonstrate the basic concepts of Cyber Threat Intelligence and Security Operations Center (SOC) workflows.

## Features

- User Authentication and Session Management
- Dashboard with Real-Time Statistics
- Threat Management (Add, Update, Delete, View)
- IOC (Indicator of Compromise) Management
- Vulnerability Management
- Alert Management
- Threat Simulation Module
- Automatic Alert Generation
- Interactive Charts and Analytics
- Responsive User Interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Chart.js
- XAMPP

## Project Workflow

1. User Login
2. Dashboard Access
3. Threat, IOC, Vulnerability, and Alert Management
4. Database Storage and Retrieval
5. Dashboard Analytics and Charts
6. Threat Simulation
7. Automatic Alert Generation
8. Secure Logout

## Educational Purpose

This project was developed for academic purposes to demonstrate practical implementation of cybersecurity concepts, database management, and full-stack web development.
